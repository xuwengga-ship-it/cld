🌐 获取公网URL - 只需一行命令！

┌─────────────────────────────────────────────────────────────┐
│  步骤1: 打开终端，切换到项目目录                            │
│                                                               │
│    cd /home/user/cld                                         │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│  步骤2: 运行一行命令                                         │
│                                                               │
│    lt --port 3000                                            │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│  步骤3: 等待10-15秒，会显示类似：                           │
│                                                               │
│    your url is: https://random-name-123.loca.lt             │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│  步骤4: 复制URL，在浏览器中打开                             │
│                                                               │
│    首次访问点击 "Click to Continue" 按钮即可                │
└─────────────────────────────────────────────────────────────┘

═══════════════════════════════════════════════════════════════

📱 使用系统所有功能：

  ✅ 图谱可视化 - 拖拽节点、缩放画布
  ✅ 周边搜索 - 选择节点，搜索关联实体
  ✅ 属性面板 - 点击查看详细信息
  ✅ 时间轴 - 查看不同时间点的图谱
  ✅ 动作按钮 - 执行对象相关操作
  ✅ 新增对象 - 批量添加实体

═══════════════════════════════════════════════════════════════

💡 高级选项：

  固定子域名:
    lt --port 3000 --subdomain my-graph-app

  后台运行:
    nohup lt --port 3000 > tunnel.log 2>&1 &
    grep "https://" tunnel.log

═══════════════════════════════════════════════════════════════

🛑 停止公网访问：

  按 Ctrl+C 或运行:
    pkill -f "lt --port"
